CONSTITUTION OF INDIA READER — INSTALLABLE WEBSITE PACKAGE

This package contains:
- index.html: the reader
- manifest.webmanifest: app name and home-screen icon settings
- service-worker.js: caching for offline use after first visit
- icons/: home-screen app icons

To make it installable on Android, host these files on an HTTPS website.
An easy free option is GitHub Pages:
1. Sign in to GitHub and create a new public repository.
2. Upload all files and the icons folder from this ZIP (not the ZIP itself).
3. In the repository, open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
5. Wait for GitHub to show your published website URL.
6. Open that URL in Chrome on your Android phone.
7. Tap Chrome's three-dot menu (⋮) > Install app or Add to Home screen.
8. Confirm. The Constitution icon will appear on your home screen.

Keep all files in the same folder structure. Do not upload only index.html.
